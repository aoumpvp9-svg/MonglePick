## 🌸 프로젝트 개요
**몽글픽(Mongle Pick)**은 점심 메뉴 결정, 팀 회의 발표자 선정, 이벤트 경품 추첨, 벌칙 뽑기 등 다양한 상황에서 무작위로 하나 또는 여러 개를 공정하고 흥미진진하게 선정해 주는 웹 애플리케이션입니다.

귀여운 토끼 마스코트 **'몽글이'**가 사용자와 함께 호흡하며 표정과 대사를 바꾸고, 룰렛 슬롯 애니메이션과 축하 폭죽(Confetti), 귀여운 효과음(Web Audio API)을 제공합니다.

---

## ✨ 핵심 기능

### 1. 🐰 반응형 마스코트 '몽글이' & 대화 말풍선
- **기본 대기 상태**: 깜찍한 호흡/부유 애니메이션과 미소
- **추첨 진행 중**: 별 모양 눈(★.★)과 흔들림 애니메이션으로 기대감 연출
- **당첨 축하 상태**: 활짝 웃는 표정과 만세 포즈, 축하 폭죽 연출
- **상호작용**: 몽글이를 직접 클릭하면 간지럼을 타거나 귀여운 응원 메시지 전달

### 2. 📝 편리하고 똑똑한 항목 관리
- **단일 등록**: 텍스트 입력창 및 Enter 키 지원
- **여러 항목 한 번에 등록 (Bulk Add)**: 줄바꿈(Enter)으로 구분된 긴 텍스트를 모달 창에서 한 번에 등록
- **공백 자동 정리**: 앞뒤 공백 및 빈 줄 자동 제거
- **중복 등록 방지 / 허용 옵션**: 옵션 토글 지원
- **후보자 태그(Chip)**: 개별 삭제(✕), 개별 추첨 제외/포함 전환 토글 지원
- **추천 세트 원클릭 불러오기**:
  - 🍱 오늘 점심 뭐 먹지? (초밥, 마라탕, 수제버거 등)
  - ☕ 카페 & 디저트 (아메리카노, 소금빵, 크로플 등)
  - 🎤 발표자 & 순서 정하기 (1조, 2조 등)
  - ⚡ 꿀잼 벌칙 뽑기 (간식 쏘기, 엉덩이 이름 쓰기 등)
- **전체 삭제**: 실수 방지를 위한 귀여운 확인 팝업 모달 제공

### 3. 🎰 두근두근 무작위 추첨 엔진
- **추첨 인원 설정**: 1명부터 5명까지 간편한 스텝 버튼(＋, －)으로 조절
- **당첨자 제외 옵션**: 이전 라운드 당첨자를 다음 추첨에서 자동으로 제외
- **슬롯머신 롤링 애니메이션**: 약 1.8초 동안 이름이 빠르게 롤링되며 프로그레스 바 작동
- **공정한 무작위 알고리즘**: 피셔-예이츠 셔플(Fisher-Yates Shuffle) 기반의 편향 없는 추첨
- **실시간 검증 및 친절한 안내**:
  - 후보가 없을 때
  - 남은 후보보다 많은 인원을 뽑으려 할 때
  - 모든 후보가 제외되었을 때 등 친절한 토스트 메시지 안내

### 4. 🎉 화려한 결과 공개 & 추첨 기록
- **결과 카드**: 🥇 1등, 🥈 2등 등 등수별 뱃지와 함께 입체감 있는 카드 팝업
- **자체 Confetti 폭죽**: 외부 라이브러리 없이 순수 HTML5 Canvas 60fps 축하 파티클 발사
- **결과 클립보드 복사**: 클릭 한 번으로 메신저/카카오톡에 바로 공유 가능한 텍스트 복사
- **추첨 기록(History)**: 회차별 당첨자와 일시를 시간순으로 기록
- **마지막 추첨 취소 (Undo)**: 실수로 뽑았거나 재추첨이 필요할 때 가장 최근 추첨을 되돌리고, 제외되었던 후보도 원래대로 자동 복구
- **기록 초기화**: 확인 팝업 후 안전하게 초기화

### 5. 🔔 순수 Web Audio API 효과음
- 외부 오디오 파일 없이 브라우저 내장 Web Audio API로 귀여운 사운드 합성
  - 룰렛 회전음 (톡톡톡)
  - 당첨 팡파르 (따라라란~ C-E-G-C 화음)
  - 버튼 클릭 / 팝업 효과음
- 상단 스위치로 효과음 ON/OFF 간편 전환

### 6. 💾 브라우저 로컬 저장소 (localStorage)
- 새로고침하거나 브라우저를 닫아도 등록된 후보 목록, 추첨 기록, 설정 옵션이 안전하게 자동 보존
- 별도의 서버나 데이터베이스 없이 영구적인 사용성 보장

## 📂 파일 구조
```
MonglePick/
├── index.html      # 시맨틱 마크업, SVG 마스코트, 모달 및 캔버스
├── style.css       # 파스텔 디자인 시스템, 글래스모피즘, 키프레임 애니메이션
├── script.js       # 상태 관리, 로컬스토리지 동기화, 오디오 합성기, 셔플 엔진
└── README.md       # 프로젝트 설명 및 가이드 문서
```

## 🚀 실행 방법
별도의 빌드나 의존성 설치 없이, `index.html` 파일을 크롬, 엣지, 사파리 등 현대 웹 브라우저에서 바로 열어서 사용할 수 있습니다.

```bash
# 로컬에서 간단한 웹 서버로 실행할 경우 (선택 사항)
npx serve .
# 또는 VS Code의 Live Server 확장 프로그램으로 index.html 실행
```
